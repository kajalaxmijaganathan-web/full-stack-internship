I also learned about the **MVT architecture** used by Django:

```text
        User
          ↓
        URL
          ↓
        View
       ↙    ↘
   Model    Template
      ↓        ↓
   Database   HTML
       ↘      ↙
       Response
          ↓
         User
```

Understanding this flow helped me connect the frontend concepts I learned earlier with backend development.

## 🔗 Connecting Frontend, Backend & Database

The most important learning from this internship was understanding how the different parts of a web application work together.

A full stack application can be understood as:

```text
👤 User
   ↓
🎨 Frontend
HTML + CSS + JavaScript
   ↓
⚙️ Backend
Python + Django
   ↓
🗄️ Database
Store & Retrieve Data
   ↓
⚙️ Backend Processing
   ↓
🎨 Frontend Response
   ↓
👤 User
```

This helped me understand that full stack development is not only about creating a webpage.

It involves connecting the **user interface, application logic, server-side processing, and database** to create a complete working application. 🚀
